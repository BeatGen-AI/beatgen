Konva Timeline Resize Test Instructions

This test verifies that resize handles are now functional in the Konva-based timeline.

What was fixed:

  1. Added onResizeStart prop to KonvaTrack component
  2. Connected resize handle mouse events to call onResizeStart
  3. Modified KonvaTimeline to pass resize handler that calls interaction.startResize
  4. Exposed startResize method from useKonvaInteractions hook

How to test:

  1. Open the Studio with Konva timeline enabled
  2. Add or select a track in the timeline
  3. Click on the track to select it (you should see selection outline)
  4. Hover over the left or right edge of the selected track
  5. The cursor should change to resize cursor (↔)
  6. Click and drag the edge to resize the track
  7. The track should resize with grid snapping if enabled
  8. Check console for resize logs: "[KonvaTimeline] onResizeStart called"

Expected behavior:

  • Left resize: Changes both position and width (trim from start)
  • Right resize: Changes only width (trim from end)
  • Grid snapping should work during resize
  • Multiple selected tracks should resize together
